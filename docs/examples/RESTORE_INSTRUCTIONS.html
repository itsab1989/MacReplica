On the old Mac

  1. Open MacReplica.
  2. Choose Create Backup and let the scan finish.
  3. Choose what should be kept, for example Python environments and application data.
  4. Save the backup.
  5. Check the backup (MacReplica does this automatically when saving; you can repeat it with Check Backup).
  6. Copy the backup folder safely to the new Mac.

Moving the backup

Copy the whole folder “MacReplica-Backup-2026-10-02-1852”, not only parts of it. Any of these works:

  • an external drive or USB stick
  • a shared folder on your network
  • a cloud folder such as iCloud Drive (wait until all files are uploaded and downloaded)
  • AirDrop, for smaller backups

On the new Mac you can choose Check Backup in MacReplica to make sure nothing was lost on the way.

On the new Mac

  1. Download MacReplica, move it to the Applications folder and open it.
  2. Choose Restore and select the backup folder.
  3. Review what MacReplica found in the backup.
  4. Choose what should be restored. Use Preview (Dry Run) to see every step first.
  5. Allow what macOS asks for: the Command Line Tools installation and your administrator password, where needed.
  6. Start the restore and keep the Mac awake until it finishes.
  7. Review the result. Failed items can be retried.
  8. Install the apps listed under “Apps to Install Manually” yourself.

Sign-ins and credentials

Restoring an app restores the app and its settings, not your login. Please keep this in mind:

  • Configuration (app settings, presets, Git settings) is restored where MacReplica supports it.
  • Sign-ins are not restored: apps and services such as Adobe, Microsoft, Google, GitHub, cloud storage and subscriptions ask you to sign in again, because their logins are tied to the old Mac.
  • The macOS Keychain is never copied. Use iCloud Keychain (Passwords app) to bring your saved passwords to the new Mac.

If something goes wrong

  • Failed items can be retried at the end of the restore, for example after signing in to the App Store or when the internet connection is back.
  • Logs are in ~/Library/Logs/MacReplica. In MacReplica, choose Help › Open Logs or Help › Export Diagnostic Report.
  • An interrupted restore continues where it stopped the next time MacReplica is opened.
